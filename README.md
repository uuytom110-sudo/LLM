# 格物 · 八年级上册复习

八年级上册复习站：**语文、历史、地理、生物学、物理**五科复习资料，加上两个数学专题：**共顶点旋转全等模型（手拉手模型）的题型研究**和**动点问题**。
界面、字符场背景、液态玻璃卡片和开场字符影片都沿用 Fuxi 复习站的美术风格。

### 手拉手模型的题型研究

- **动手旋转**：可拖动的互动图形。选等边三角形 / 等腰直角三角形 / 正方形 / 任意顶角，转动小图形，实时显示 BD、CE 的长度、∠BFC、FA 平分的角，并标出始终全等的 △ABD 与 △ACE；一键跳到“D 在 AB 上”“B、D、E 共线”等特殊位置。
- **题型研究**：每道例题配准确的几何图（坐标由程序计算，所有角度、线段关系都经过数值验证），可以「标出全等三角形」「一步一步看思路」「看完整解答」，附方法小结和变式练习。
- **真题**：收录近年期末、月考、中考模拟卷中的手拉手题（如 2022春·驻马店期末、2022秋·重庆期末、2023·定西模拟），题干按原题条件改写并标注来源；图形同样由代码按题目条件生成。练习里可以单独点「真题」只做这些题。
- **图形全部由代码绘制**：49 道练习题中 47 道带图（另外 2 道是纯概念题），图形描述在 `data/model.js`、`data/model-exam.js` 的 `fig` 字段里。
- 只用八年级上册的知识（三角形内角和与外角、SSS/SAS/ASA/AAS/HL、角平分线的性质与判定、等腰与等边三角形）。

### 动点问题

- **会动的例题**：每道例题的图形都能拖动时间滑块 t，或点「▶ 播放运动过程」看点怎么走；图下实时显示各条线段的长度（用 t 表示）和此刻是否满足条件，答案对应的时刻有快捷按钮，一点就停在那一刻。
- **分类不漏**：全等题按对应关系分情况（如点 Q 的速度有两种取值时可以切换），等腰题按顶角顶点分三类，直角题按直角顶点分类，并逐一检验 t 是否在运动范围内。
- **最短路径**：将军饮马和两次对称都能拖动点的位置，实时看到 PA + PB（或三角形周长）的变化，最小值出现在对称点连线与直线的交点处。
- 只用八年级上册的知识（全等、等腰三角形、轴对称、勾股定理以前的内容），所有数值都经过程序验证。

### 语文、历史、地理

- **语文**：在 Fuxi 语文部分的基础上，按新教材的变化整理（第一单元新增《中国人首次进入自己的空间站》，第二单元换成《回忆鲁迅先生》《天上有颗“南仁东星”》，整本书阅读换成《红岩》）；补充了《消息二则》《国行公祭》、藤野先生的几件事、《中国石拱桥》《苏州园林》《梦回繁华》、愚公移山与周亚夫军细柳的要点，两张文言词语表、重点句子翻译，以及 33 道新题。
- **历史**：按 2025 年秋季新教材的 7 个单元、22 课重新分章（如第 10 课“帝制复辟与军阀割据”、第 18 课“全民族抗战中的正面战场和敌后战场”、第 22 课活动课“探寻红色文化的历史基因”），补全了后半学期的内容，新增 37 道题和对照表专题。
- **地理**：沿用 Fuxi 中国地理部分，补充三级阶梯剖面图（由代码绘制）、气候类型与分布表、影响气候的因素、外流区与内流区、农业因地制宜等内容，以及 23 道新题和 10 道高频题。
- 题目的选项顺序由程序固定打乱，解析里不再用“A 项 / B 项”指代选项。

### 版面

- 知识点：小标题前有专题颜色的竖条，关键词用专题颜色标出，正文两端对齐；章节标题拆成“第几单元 / 第几课”和标题两行，折叠箭头在右侧。
- 表格在手机上自动变成一行一张的小卡片（“列名：内容”），不用左右滑动；字符示意图按“汉字占两格”的网格对齐，窄屏自动缩小。
- 科目页头部：电脑上放字符画，手机上放线描小图；头部的字符场只在右侧流动，不压在文字下面；全站背景字符场在两侧页边保持原样，正文那一栏后面调暗。

### 其他功能（与 Fuxi 相同）

练习即时批改、错题本（做错自动收录，答对自动移出）、综合模拟（交卷后统一批改）、背诵卡翻面自测、全站搜索、深色 / 浅色模式、键盘答题。选择题的选项顺序按题目固定打乱，避免答案扎堆。

打开时是 Fuxi 原版的字符画短片《从原子到视界》（WebGL 实时渲染：氢原子轨道 → 克拉德尼共振 → 墨流 → 洛伦兹吸引子 → 朱利亚集 → 叶序黄金角 → 密度波星系 → 黑洞视界），整体加速约 2.8 倍。最后一帧画面上的每一个字符都化成粒子，螺旋聚拢，凝成精细的字符画单词 **access**——它就是进入按钮——随后不加任何标注地在中文、日语、韩语、法语、德语、西班牙语、俄语、意大利语、希腊语、阿拉伯语、印地语之间轮换，背景微粒继续流动。约 18 秒后可以点击进入；每次打开网页都会播放，按 Esc 随时跳过；播放时页面背景的字符场暂停绘制（它们被盖住，却会和影片抢主线程），字符着色在字符网格分辨率上完成、全分辨率只做三次取样，手机上最高按 2 倍像素渲染，持续掉帧时自动降一档画质，各国语言的单词在空闲时提前准备好；首页底部可重播；画面按屏幕实际大小铺满（手机竖屏、横屏、平板、宽屏电脑都不留黑边）；不支持 WebGL 时自动使用 2D 版（同样由最后一帧的字符聚成 access）；系统开启“减少动态效果”时照常播放，但轻点任意位置即可跳过。

做题记录保存在**当前浏览器**里，换设备或清除浏览器数据后会重新开始。

## 怎么打开

- **在线访问（现在就能用）**：<https://htmlpreview.github.io/?https://github.com/uuytom110-sudo/LLM/blob/claude/hopeful-ptolemy-gvany5/index.html> ——由 htmlpreview.github.io 直接读取本仓库的最新代码显示，推送后几分钟内自动更新。
- **本地运行**：直接用浏览器打开 `index.html`，或在仓库目录运行 `python3 -m http.server` 后访问 `http://localhost:8000`。
- **离线单文件**：运行 `python3 scripts/build_single.py`，生成 `dist/gewu-offline.html`，一个文件包含全部内容，双击即可打开。
- **在线地址**：<https://uuytom110-sudo.github.io/LLM/>（GitHub Pages，推送后自动更新）。
- **GitHub Pages / 自己的域名**：推送后 `.github/workflows/pages.yml` 自动构建发布。第一次需要在仓库 **Settings → Pages → Source** 选择 **GitHub Actions**；绑定自己的域名（不需要服务器）的完整步骤见 [DEPLOY.md](DEPLOY.md)。

## 修改内容

题目、知识点、例题都在 `data/` 目录下（`chinese.js`、`history.js`、`geography.js`、`biology.js`、`physics.js`、`model.js`、`model-exam.js`、`motion.js`），格式与 Fuxi 相同：

```js
questions: [
  { ch: '章节id', type: 'choice', q: '题干', opts: ['A', 'B', 'C', 'D'], a: 1, ex: '解析' },  // a 是正确选项的序号，从 0 开始
  { ch: '章节id', type: 'tf', q: '判断题', a: true, ex: '解析' },
  { ch: '章节id', type: 'fill', q: '填空题 ______', a: ['答案', '另一种写法'], ex: '解析' }
]
```

几何图形用 `fig` 字段描述（点的坐标 + 要画的多边形、线段、角、全等三角形），由 `js/geo.js` 渲染，写法见该文件开头的注释。动点例题的 `dyn` 字段给出时间范围、速度和 `fig(t)` 函数，图形随 t 重新计算。改完后运行 `node scripts/check_data.js` 检查答案下标、章节和图形。

生物学、物理、地理按 2024 年审定、2025 年秋季起使用的新版人教版八年级上册整理，语文、历史按 2025 年秋季起使用的统编版新教材整理；不同地区教材版本和考试范围可能不同（例如苏科版物理章节顺序不同），请以课本和老师划的重点为准。
